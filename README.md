# Rute Fonseca — draft site

Static page, no server. Portuguese and English. The contact form opens WhatsApp.

The Instagram bar is the three posts listed at the top of `app.js`. Instagram does not provide a live feed without a backend, so that list is edited by hand.

Photos and videos in `media/` are copies of her public Instagram posts, so they play on the page without a server. Replace the files to update them.

Preview locally:

```
python -m http.server 8765
```
